# 验收契约

## 范围

本 change 只改验收跑法（UAT 手册提示词）与状态记录，不改任何产品代码与规格。

## 必验

- 新提示词包含约束句「建目标的本轮不要写任何正文」，且与实机验证场（`8ec5e70e…`）用的表述一致。
- 场次 3 状态改为通过时，**原「未验收」记录与首次人跑「不太行」记录保留不抹掉**（本项目纪律：判据/状态修订不删历史）。
- `restore-chat-streaming/tasks.md` 3.3 保持未勾（场次 4 仍待人跑），不因场次 3 通过而归档。

## 不验

- 不跑真端点：约束句已有实机验证（`8ec5e70e…`），手册改动本身无需再跑。
- 不跑单测/变异：零代码改动。
