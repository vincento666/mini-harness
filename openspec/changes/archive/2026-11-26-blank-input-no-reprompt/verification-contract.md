# 验收契约：空白输入不重打提示符

## 自动化判据（黑盒，mock fixture，`--no-stream`）

1. **首条前空白**：stdin `"\n第一条\n"`，fixture 一条回复 → stdout 逐行 `["> ", "> 回复一", "> "]`；`prompt` 词 `> ` 恰出现两次。
2. **两条输入间空白**：stdin `"第一条\n\n第二条\n"` → stdout `["> 回复一", "> 回复二", "> "]`。
3. **末尾空白**：stdin `"第一条\n\n"` → stdout `["> 回复一", "> "]`，末尾不含第二条 `> `。
4. **命令后回到提示符**：stdin `"/skills\n\n"` → `/skills` 清单照常打印，其后无多余提示符。
5. **回归**：无空白的既有断言（`["> 你好", "> "]` 等）逐点不变；空白不开轮的日志规则不变。

## 变异

- M1 空白输入重打提示符（还原旧行为）→ 判据 1/2/3 杀。
- M2 命令处理完不置旗标（`/skills` 后提示符消失）→ 判据 4 杀。
- M3 旗标在轮处理后不置真（回复后没有提示符）→ 判据 1/2/3 杀。

## 不验什么

- 不验 tty 粘贴手感（ADR-0025 适用的是 UX 手感场次；本判据是纯排版行为，黑盒足够；pty 抽查作为辅助证据，不设手感场次）。
- 不验日志：提示符不进日志，空白输入不开轮的既有规则不动。
