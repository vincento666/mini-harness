# 验收契约：goal-ux-one-line

## 范围

只改「模型能不能自己分轮」的输入（受保护政策段 v3 + `create_goal` 描述），不改引擎的续跑/停止机制，不改 `[轮]` 计数与显示。

## 必验

1. **版本冻结**：`GOAL_POLICY_VERSIONS` 里 v1/v2 原文逐字未变；`GOAL_POLICY_VERSION == "v3"` 且命中表。旧日志 replay 的逐点一致判据仍绿（`test_replay_of_a_log_with_the_goal_policy_still_verifies`）。
2. **政策文本覆盖三条新句子**：一句话任务先建目标、建目标那轮只做计划、每轮只推进一块 + 简单问答不建目标。缺任一条即不通过（否则等于没解决）。
3. **工具描述是条件句**：写到「需要多步/多轮时使用」「建完结束本轮、正式内容从目标轮 1 开始」，且不承诺无条件创建。
4. **真实端点（决定性）**：3 场不同任务的**一句话提示词**（不含任何流程说明），逐场记录：是否建目标、每轮是否只推进一块、是否在轮边界停下、完成是否走 `update_goal complete`。允许模型选择「不建目标、单轮答完」的场景（如「讲个笑话」），但编码类多步任务必须出现分轮。
5. **门禁**：`uv run pytest`、`ruff format --check`、`ruff check`、`mypy --strict`、`openspec validate --all --strict`。

## 不验

- 不验「模型一定建目标」：判定权仍在模型，本 change 只提供依据；把「不建目标」当失败会逼出过度反应。
- 不验 tty 手感：本 change 不动渲染。

## 变异（至少两条）

- M1：把 v3 的「建目标的那一轮只做计划」删掉 → 判据 2 必须失败。
- M2：把 `GOAL_POLICY_VERSION` 留在 `"v2"` → 新会话不注入 v3，判据 1/2 必须失败。
