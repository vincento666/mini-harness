# M12 subagent UAT

**状态**：等人跑。

## 场次

### S1 · 一次委派

让父代理调用 `subagent` 做一个独立小任务；看父结果里有子任务最终文本，父日志只有一对 tool 记录。

### S2 · 并行

同一批派两个子代理；体感上差不多同时完成，父结果两条。

### S3 · 深度/容量

- 子代理内再调 subagent → `DEPTH_EXCEEDED`；
- 第 9 个子代理 → `ACTIVATION_LIMIT_REACHED`。

### S4 · 审批

子代理触发需审批的工具；应得到 `UNAVAILABLE`，不能静默放行。

### S5 · 取消

父段在子代理运行中取消；子会话 ABORTED，父没有孤儿任务。
