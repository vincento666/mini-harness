# 压缩是影子覆盖：日志不删，遮蔽范围是一条替换记录

窗口装不下时有三条路：删掉旧记录、把表层另存一份投影、旧记录留着但声明它们不再进上下文。裁决**第三条**——一条 `compaction/summary` 记录带 `shadowed_range {start, end}`，读方（折叠与 replay）从此跳过这个范围里的记录。理由是不变量 A：日志唯一真源、只追加不改写；删记录就是改写历史，而 M1 起每条 replay 判据都建立在「任何前缀可重算」之上，删了就再也判不了。这也是 DSH 的形状（它的 `compaction/summary` 与 `compaction/prune` 都带 `shadowedRange`）。

Considered options：物理删除旧记录（否：违反不变量 A，且「这条压缩遮蔽了哪些」这条事实就没有载体了）；另建一份表层投影文件（否：两份真源，replay 要判的是哪一份？）；只在内存里跳过、日志里不留痕（否：下一次装配要从日志重算，没有痕就不知道上次遮蔽了什么，压缩等于没发生）。

Consequences：遮蔽范围本身要能被重放判（`tests/test_cli_replay.py` 里那条「发生过压缩的日志逐点重放」）；日志因此**变长**，而回合循环每回合全量读一遍——这笔账记在 ADR-0002。多次压缩的遮蔽范围允许重叠，既有摘要不被遮蔽。
